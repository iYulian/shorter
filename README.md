## Требования и запуск

- JDK 21 или новее; сборка проверена на JDK 21.
- Maven 3.9+ для сборки и тестов.

Из каталога с `pom.xml`:
```bash
mvn clean verify
java -jar target/uri-shorter-1.0.0.jar
```

## Работа с приложением

При первом запуске программа сразу предлагает зарегистрироваться. Введите логин
и пароль. Если пользователи уже есть в текущем процессе, можно выбрать вход или
регистрацию. Пароль вводится обычным `Scanner` и виден в консоли.

| Главное меню | Действие |
|---|---|
| 0 | Завершить работу |
| 1 | Сменить пользователя |
| 2 | Работа со ссылками |

| Меню ссылок | Действие |
|---|---|
| 0 | Вернуться в главное меню |
| 1 | Зарегистрировать ссылку |
| 2 | Открыть исходный URL по сокращению |
| 3 | Показать ссылки текущего пользователя |
| 4 | Открыть меню редактирования |
| 5 | Удалить ссылку |

| Меню редактирования | Действие |
|---|---|
| 0 | Вернуться в меню ссылок |
| 1 | Изменить исходный URL |
| 2 | Изменить общий лимит переходов |
| 3 | Изменить время жизни |

### Пример

1. Зарегистрируйте пользователя `alice`.
2. В главном меню выберите `2`, затем в меню ссылок `1`.
3. Введите `https://example.org/page?q=1`.
4. Скопируйте выданное сокращение, например `short.ru/Ab12Cd`.
5. Выберите `2` в меню ссылок и вставьте сокращение целиком.
6. Для изменения лимита выберите `4`, затем `2`, введите сокращение и новый лимит.
7. Для изменения TTL выберите `3` в меню редактирования, сокращение, знак `+` или `-`
   и число секунд. Например, `+` и `60` добавят минуту к прежнему сроку.
8. Для удаления вернитесь в меню ссылок, выберите `5`, сокращение и `1` для подтверждения.

`0` отменяет выбор сокращения, ввод URL, выбор логина и регистрацию на этапе ввода
логина. Отмена смены пользователя сохраняет текущего пользователя. Если активного
пользователя нет, отмена завершает приложение. При пустой коллекции ссылок программа
возвращается в меню.

Сокращения открываются через консоль.

## Настройки

Единственный источник конфигурации — `src/main/resources/application.properties`.
После изменения файла пересоберите приложение и перезапустите его.

```properties
shorter.default-ttl-seconds=120
shorter.default-call-limit=3
shorter.code-length=6
shorter.base-url=short.ru
shorter.cleanup-interval-seconds=1
shorter.generation-attempts=1000
```

| Параметр | Допустимые значения |
|---|---|
| `shorter.default-ttl-seconds` | 1–315360000 секунд |
| `shorter.default-call-limit` | 0–2147483647 |
| `shorter.code-length` | 1–64 символа |
| `shorter.base-url` | Непустой префикс без пробельных символов |
| `shorter.cleanup-interval-seconds` | 1–86400 секунд |
| `shorter.generation-attempts` | 1–100000 |

`UriShorterConfig` проверяет значения и создаёт единственный экземпляр через `Holder`.
Настройки не перечитываются во время работы. Отсутствующий файл или некорректное
значение может привести к ошибке инициализации при запуске. 

## Правила работы

### Пользователи и доступ

Каждый пользователь получает UUID. Логин состоит из 1–64 символов латиницы, цифр,
`_`, `.`, `-`; логин `0` зарезервирован для отмены. Пароль не должен быть пустым,
состоять только из пробелов или превышать 1024 символа.

Сервис проверяет, что переданный объект пользователя совпадает с зарегистрированным
объектом, найденным по UUID. Затем он ищет ссылку в коллекции этого пользователя.
Чужие ссылки нельзя открыть, отредактировать или удалить. UUID сам по себе не заменяет вход по паролю.

### Сокращение

Код генерируется через `Random` из латинских букв и цифр. Перед вставкой выполняется
проверка совпадений среди ссылок всех пользователей. При совпадении генерируется
новый код; число попыток ограничено конфигурацией.

Повторный непросроченный URL у одного пользователя возвращает прежнее сокращение,
даже если его лимит исчерпан. Разные пользователи могут сокращать один URL независимо.
Редактирование URL в другой уже существующий непросроченный URL владельца запрещено.

### Переходы и лимит

Лимит — общее число разрешённых переходов. Счётчик увеличивается после успешного
возврата `Desktop.browse()`. Ошибка при открытии не расходует переход.
Успешный вызов браузера не подтверждает загрузку страницы или HTTP 200.

Лимит `0` блокирует переходы. Снижение лимита до использованного числа или ниже
также блокирует ссылку. Повышение лимита разрешает новые переходы, если TTL ещё
не истёк. После последнего разрешённого перехода выводится уведомление.

### TTL и удаление

Ссылка истекает при достижении времени истечения ссылки. Переход блокируется по сроку независимо от того, успела ли очистка удалить запись.

Планировщик вызывает очистку: интервал отсчитывается от завершения предыдущего обхода. Удаление не происходит строго в момент истечения.
При очистке печатаются сокращение, логин и UUID владельца.

TTL редактируется относительно текущего `activeTo`. Уже просроченную ссылку нельзя
продлить через сервис. Можно заново зарегистрировать исходный URL. Вычитание времени может сделать ссылку просроченной.
Ручное удаление выполняется после подтверждения владельца.

## Структура

| Класс | Назначение |
|---|---|
| `UriShorterMainMenu` | Главное меню и жизненный цикл приложения |
| `UriShorterUserService` | Регистрация, вход, хранение пользователей и проверка UUID |
| `UriShorterUriService` | Меню ссылок, создание, редактирование, удаление и проверки |
| `URIShorterUtil` | Чтение ввода, проверка URL и генерация сокращения |
| `ShortedUriExecuterService` | Вызов браузера и учёт переходов |
| `ShortedUriObserver` | Периодическая очистка |
| `UriShorterConfig` | Чтение и валидация настроек |
| `User`, `UriWrapper` | Пользователь и состояние ссылки |
| `PasswordInvalidException`, `UserDuplicateException` | Ошибки входа и регистрации |
